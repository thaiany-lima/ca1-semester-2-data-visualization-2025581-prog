# Data Preparation & Visualization — Case Study

Academic data analytics project focused on preparing, exploring and visualizing a dataset using Python and Jupyter Notebooks.

## Project Overview

This project focuses on data preparation, exploratory analysis and data visualization.

The project includes two main notebooks:

* Data Preparation: data cleaning and preparation.
* Data Visualization: exploratory analysis and visualizations to identify patterns and communicate insights.

Tools & Technologies

* Python
* Jupyter Notebook
* Pandas
* Data Cleaning
* Exploratory Data Analysis
* Data Visualization

Repository Contents

* Thaiany_DPrepHdip_CA1.ipynb — data preparation and cleaning.
* Thaiany_DVizHDip_CA1.ipynb — data visualization and analysis.
* Case Study.docx — project case study.

## Purpose

This project demonstrates practical experience working with datasets, preparing data for analysis, exploring information and presenting findings through visualizations.
